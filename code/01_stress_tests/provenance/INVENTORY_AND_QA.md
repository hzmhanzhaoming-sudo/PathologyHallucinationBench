## 明确边界

1. 新生成回答不承诺逐条等于历史回答；代码保留当前服务器评估脚本，历史每次请求的所有运行时配置仍应依据原始运行记录核对。不能声称当前脚本默认值自动等于每个历史 API 请求。
2. 新评分检查已保存预测标签、gold、correct、options、question、输入哈希与样本集合，不重新解析自由文本，不偷偷应用历史答案修复。
3. 新评分采用完整精度；历史 V2/T3 图源可能使用三位小数的中间百分比。应在论文复算报告中显式披露该显示精度差，不用硬编码旧数值拟合新计算。
4. V1 的图像正确数不超过随机期望、或 T1 某正确/错误机会集合为空时返回未定义。历史图笔记本对 T1 空分量填零；当前审计的 16 模型不触发该边界，因此不改变已发表式结果。
5. 新入口默认不写结果、无隐式覆盖/续写；执行需显式 `--execute --run-id`。小规模 `--limit` 输出隔离。写报告禁止进入原数据/原结果/原图目录。
